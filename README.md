# Sala de Eventos Ohana — Web demo

Sitio web demo de **Sala de Eventos Ohana**, un salón de eventos en Humanes de Madrid.

- **Stack:** Next.js 16 · React 19 · TypeScript · Tailwind CSS 4 · Motion
- **Contenido centralizado** en `src/site.ts` (marca, textos, imágenes).
- **Datos reales:** teléfono, dirección y redes sociales del negocio. Las
  fotografías del espacio son imágenes de referencia (Pexels) a la espera de las
  fotos reales del salón.

## Desarrollo

```bash
npm install
npm run dev      # http://localhost:3000
npm run build    # build de producción
npm start        # servir el build
npm run lint     # eslint
```
